## Goal

Publish the template so the platform can stamp agents from it: push it to GitHub, and mark the repository as a template.

## Starting point

Continue in the template from lesson 04:

```bash
cd lab/template
```

## Steps

1. Commit the template.
2. Create the repository and push.
3. Mark it as a template.

### 1. Commit the template

```bash
git init -b main
git add .
git commit -m "Agent template"
```

`.gitignore` keeps `node_modules`, `dist` and `.wrangler` out of the commit.

### 2. Create the repository and push

```bash
gh repo create agent-template --private --source . --push
```

Keep the name `agent-template`: the Terraform module looks for it in lesson 07.

### 3. Mark it as a template

```bash
gh repo edit --template
```

## Run and verify

```bash
gh repo view --json name,isTemplate,visibility
```

You should see:

```txt
{
  "isTemplate": true,
  "name": "agent-template",
  "visibility": "PRIVATE"
}
```

## Success check

You are ready for the next lesson when:

- `gh repo view` shows `"isTemplate": true`.
