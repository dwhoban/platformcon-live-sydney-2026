## Goal

Stamp the agent's code: a new repository generated from the template, with the secrets and variables its deploy workflow needs. After this, the agent deploys itself on every push to `main`.

## Starting point

Continue in the Terraform folder from lesson 06:

```bash
cd lab/terraform
```

## Steps

1. Create the repository, secrets and variables.

### 1. Create the repository, secrets and variables

Create this file:

```txt
github.tf
```

Add:

```hcl
# The agent's code: a new repository generated from the template.
resource "github_repository" "agent" {
  name        = var.agent_name
  description = "AI agent ${var.agent_name}, stamped from ${var.github_owner}/${var.template_repo}"
  visibility  = "private"

  template {
    owner      = var.github_owner
    repository = var.template_repo
  }
}

# What the deploy workflow needs to deploy to your Cloudflare account.
resource "github_actions_secret" "cloudflare_api_token" {
  repository  = github_repository.agent.name
  secret_name = "CLOUDFLARE_API_TOKEN"
  value       = var.cloudflare_api_token
}

resource "github_actions_secret" "cloudflare_account_id" {
  repository  = github_repository.agent.name
  secret_name = "CLOUDFLARE_ACCOUNT_ID"
  value       = var.cloudflare_account_id
}

# Identity: the name the workflow deploys under, and the gateway its model
# calls go through.
resource "github_actions_variable" "agent_name" {
  repository    = github_repository.agent.name
  variable_name = "AGENT_NAME"
  value         = var.agent_name
}

resource "github_actions_variable" "ai_gateway_id" {
  repository    = github_repository.agent.name
  variable_name = "AI_GATEWAY_ID"
  value         = cloudflare_ai_gateway.agent.id
}

output "repo" {
  value = github_repository.agent.full_name
}

output "repo_url" {
  value = github_repository.agent.html_url
}
```

The repository starts as a copy of `agent-template`, deploy workflow included. The two variables are the agent's identity: `AGENT_NAME` becomes the Worker's name and `AGENT_ID`, and `AI_GATEWAY_ID` points the agent at the gateway from lesson 05. Nothing in the agent's code changes.

## Run and verify

```bash
terraform apply
```

Then check the new repository:

```bash
gh secret list --repo "$(terraform output -raw repo)"
gh variable list --repo "$(terraform output -raw repo)"
```

You should see the two secrets, `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`, and the two variables, `AGENT_NAME` and `AI_GATEWAY_ID`.

## Success check

You are ready for the next lesson when:

- `terraform apply` finished with `5 added`.
- `terraform output repo_url` opens a repository named after your agent.
- The repository has both secrets and both variables.
