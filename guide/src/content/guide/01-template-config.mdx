## Goal

Give the template three of its five defaults. Right now the agent calls Workers AI directly, nothing records which agent or which user made a call, nothing caps the work one request can do, and once it is deployed you have no traces.

By the end of this lesson:

- every model call goes through AI Gateway and carries `agent_id` and `user_id`
- every request has a CPU ceiling
- every request, Durable Object call and model call is traced

## Starting point

Use the template from the lab folder:

```bash
cd lab/template
```

The agent is a Durable Object class called `Agent` in `src/server.ts`. Each browser gets its own user id, and each user gets their own `Agent` instance, so one deployment serves many users, each with private state.

Each change in this lesson goes where a `// Lesson 01` comment is, in `wrangler.jsonc` and `src/server.ts`.

## Steps

1. Give the agent an identity.
2. Cap CPU time per request.
3. Turn on tracing.
4. Generate types.
5. Route model calls through AI Gateway.
6. Show the agent's identity in the UI.

### 1. Give the agent an identity

Open:

```txt
wrangler.jsonc
```

Find this line:

```jsonc
	// Lesson 01: identity goes here.
```

Replace it with:

```jsonc
	// Identity: who this agent is, and which AI Gateway its model calls use.
	// "default" is created on first use. CI replaces both with the agent's
	// own name and gateway.
	"vars": {
		"AGENT_ID": "agent-template",
		"AI_GATEWAY_ID": "default"
	},
```

`vars` become environment variables on the Worker: `env.AGENT_ID` and `env.AI_GATEWAY_ID`. Until your agent gets its own gateway in lesson 05, its model calls use your account's `default` gateway, which AI Gateway creates on the first call.

### 2. Cap CPU time per request

Find this line:

```jsonc
	// Lesson 01: usage limits go here.
```

Replace it with:

```jsonc
	// Hard usage limits: an agent stuck in a hot loop is stopped after 10
	// seconds of CPU time in one request, a third of the default.
	"limits": {
		"cpu_ms": 10000
	},
```

The limit counts CPU time, not wall time: waiting for the model or for an approval costs nothing. The agent's spend and rate limits come in lesson 05.

### 3. Turn on tracing

Find this line:

```jsonc
	// Lesson 01: tracing goes here.
```

Replace it with:

```jsonc
	// End-to-end tracing: logs and traces for every request, Durable Object
	// call and model call.
	"observability": {
		"enabled": true,
		"traces": {
			"enabled": true
		}
	},
```

That is all the tracing code there is. The Workers runtime traces every request, Durable Object call, storage operation and outbound call, model calls included.

### 4. Generate types

```bash
pnpm types
```

`wrangler types` reads `wrangler.jsonc` and rewrites `env.d.ts`, so `env.AGENT_ID` and `env.AI_GATEWAY_ID` are typed in your editor.

### 5. Route model calls through AI Gateway

Open:

```txt
src/server.ts
```

Find these lines:

```ts
  // Lesson 01: route model calls through this agent's AI Gateway.
  readonly ai = createAI({ binding: this.env.AI });
```

Replace them with:

```ts
  // Identity: every model call goes through this agent's AI Gateway and
  // says which agent and which user made it.
  readonly ai = createAI({
    binding: this.env.AI,
    id: this.env.AI_GATEWAY_ID,
    metadata: {
      agent_id: this.env.AGENT_ID,
      user_id: this.ctx.id.name ?? this.ctx.id.toString()
    }
  });
```

`createAI` sends the gateway id and the metadata with every model call through the `AI` binding. The binding is already authenticated, so there is no gateway token to manage. `this.ctx.id.name` is the name the Durable Object was created with: the user id from the URL `/agents/agent/<user>`.

<Details summary="Complete src/server.ts after this lesson">

```ts
import { DurableObject } from "cloudflare:workers";
import { Workspace, type DurableObjectStorageLike } from "@cloudflare/computer";
import { WorkerJavaScriptBackend } from "@cloudflare/computer/backends/worker-javascript";
import { createGitClient } from "@cloudflare/computer/git";
import { createGitModule } from "@cloudflare/computer/modules/git";
import { createModels } from "@earendil-works/pi-ai/models";
import { createRegistry, Harness } from "@earendil-works/pi-durable";
import { routeAgentRequest } from "agents";
import { PiHarness } from "agents/harness/pi";
import { Lifecycle } from "agents/lifecycle";
import { createAI } from "agents/models/pi-ai";
import { WebSockets } from "agents/websockets";
import { PiSessionSockets } from "./sockets";
import { createWorkspaceTools, JAVASCRIPT_BACKEND } from "./workspace";
// Lesson 02: scope the tools and gate write actions here.

const MODEL_ID = "@cf/zai-org/glm-5.3-flash";

const PREAMBLE =
  "You are a concise assistant. You have a durable workspace at /workspace: read, write, edit, list (ls), find and grep files there, and run JavaScript modules in it with exec, which can also use git. Paths are absolute. Use tools whenever they can answer the request, and explain their results plainly. If a tool you need is not available, say so.";

/** One agent instance per user, backed by one Durable Object. */
export class Agent extends DurableObject<Env> {
  // Identity: every model call goes through this agent's AI Gateway and
  // says which agent and which user made it.
  readonly ai = createAI({
    binding: this.env.AI,
    id: this.env.AI_GATEWAY_ID,
    metadata: {
      agent_id: this.env.AGENT_ID,
      user_id: this.ctx.id.name ?? this.ctx.id.toString()
    }
  });
  // A durable filesystem on the object's SQLite, beside pi's own tables.
  // `exec` runs JavaScript modules in a fresh Dynamic Worker per call, with
  // no network of its own. `git` turns on `workspace.git`, which the `ws:git`
  // module calls in the host; `allowNetwork` lets it clone, fetch and push.
  readonly workspace = new Workspace({
    storage: this.ctx.storage as unknown as DurableObjectStorageLike,
    git: createGitClient(),
    backends: [
      new WorkerJavaScriptBackend({
        id: JAVASCRIPT_BACKEND,
        loader: this.env.LOADER,
        root: "/workspace",
        access: "read-write",
        modules: { "ws:git": createGitModule({ allowNetwork: true }) }
      })
    ]
  });
  readonly registry = createRegistry();
  readonly harness = new PiHarness({
    harness: async ({ storage, context, onWake }) => {
      // Lesson 02: offer only the TOOLS, and gate the APPROVAL_REQUIRED ones.
      const tools = createWorkspaceTools(this.workspace);
      // pi's own extension: the system prompt and the tools.
      this.registry.install({
        name: "agent",
        sections: [{ key: "preamble", render: () => PREAMBLE, tag: false }],
        tools
      });
      const models = createModels();
      models.setProvider(this.ai.provider);
      return Harness.open(
        storage,
        {
          models,
          registry: this.registry,
          onWake,
          settings: {
            // pi doubles the delay before each retry: 1, 2, 4, 8 and 16 seconds,
            // so a rate-limited model gets about 30 seconds to recover.
            retry: { enabled: true, maxRetries: 5, baseDelayMs: 1000 }
          },
          onReport: (error) => console.warn("pi report", error)
        },
        context
      );
    },
    defaults: { model: this.ai(MODEL_ID), thinkingLevel: "low" }
  });

  // App glue, not the harness: how this app puts sessions on a socket.
  // Lesson 02: create the approval gate and hand it to the sockets.
  readonly sockets = new PiSessionSockets(
    this.harness,
    this.registry,
    (tag) => this.ctx.getWebSockets(tag)
  );
  readonly webSockets = new WebSockets(this.sockets.options());
  readonly lifecycle = Lifecycle.install(this)
    .use(this.webSockets)
    .use(this.harness);

  /** Host startup, after the harness has opened pi. */
  async onStart(): Promise<void> {
    await this.sockets.reattach();
  }
}

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    if (new URL(request.url).pathname === "/api/agent") {
      // Who this deployment is, for the client's header.
      return Response.json({
        agent: env.AGENT_ID,
        gateway: env.AI_GATEWAY_ID,
        model: MODEL_ID
      });
    }
    try {
      return (
        (await routeAgentRequest(request, env, { cors: true })) ??
        new Response("Not found", { status: 404 })
      );
    } catch (error) {
      console.error("Agent request failed", error);
      return Response.json(
        { error: error instanceof Error ? error.message : String(error) },
        { status: 500 }
      );
    }
  }
} satisfies ExportedHandler<Env>;
```

</Details>

## Run and verify

Stop any running dev server with **Ctrl+C**, then start it:

```bash
pnpm start
```

Open [http://localhost:5173](http://localhost:5173). The header now shows `agent-template`, your user id, and `gateway default`.

Select **Write a file** and send it. The agent writes the file and reads it back, without asking anyone. You fix that in the next lesson.

Open the Local Explorer at [http://localhost:5173/cdn-cgi/local/explorer/observability](http://localhost:5173/cdn-cgi/local/explorer/observability). The newest traces show your WebSocket connection to the agent, and the Durable Object work behind each turn: storage calls, alarms and the model subrequest.

The `AI` binding is remote, so even local model calls go through AI Gateway on your account. In the [Cloudflare dashboard](https://dash.cloudflare.com/), go to **AI** > **AI Gateway** > **default** > **Logs** and open the newest log. Its custom metadata shows `agent_id: agent-template` and your `user_id`.

## Success check

You are ready for the next lesson when:

- The header shows `agent-template` and `gateway default`.
- The Local Explorer shows traces for your message.
- The newest log in the `default` gateway has `agent_id` and `user_id` metadata.
